# レンチ

レンチは**ポートの面ごとの IO** と**外部ブロックのポート登録**を設定する道具です。
どちらも見た目からは分からない設定なので、レンチは**持っているだけで対象をハイライト**します。

## 1. 操作の一覧

| 操作 | 対象 | 結果 |
|---|---|---|
| **右クリック** | ポート | クリックした区画の面の IO を次に進める（なし → 入力 → 出力 → …） |
| **左クリック** | ポート | 同じものを逆に戻す（ブロックは壊れません） |
| **右クリック** | 何もない空間 | 選択中のポート種別を次に進める |
| **スニーク + 右クリック** | 何もない空間 | 選択中のポート種別を前に戻す |
| **スニーク + 右クリック** | コントローラ | そのコントローラにリンクする |
| **スニーク + 右クリック** | それ以外のブロック | リンク先のコントローラに、そのブロックを**選択中の種別の外部ポート**として登録する |
| **スニーク + 左クリック** | 何でも | リンクを解除する |

> [!IMPORTANT]
> **外部ポートの登録には、先にコントローラへのリンクが必要です。**
> リンクしていないレンチでブロックをスニーク + 右クリックしても何も起きません。
> リンクの有無はツールチップと、下記のハイライトで分かります。

## 2. どの面が選ばれるか

ポートの面は 3 × 3 の区画に分かれていて、**クリックした区画が「どの面の IO を変えるか」を決めます**。
面そのものではなく、**区画が近い方の面**が選ばれます。

| 区画 | 選ばれる面 |
|---|---|
| 中央 | クリックした面そのもの |
| 縁（4 箇所） | その縁が接している隣の面 |
| 角（4 箇所） | クリックした面の**反対側**の面 |

区画の割り振りはワールド座標で決まります。上面の北寄りの縁をクリックすれば北面、
西面の上寄りの縁をクリックすれば上面です。

レンチを持ってポートを見ると、この 3 × 3 のグリッドが面に描かれます。
カーソルの下の区画が塗られ、**中央は緑・それ以外は黄**です。

面の現在の IO は WAILA のツールチップに出ます。**カーソルを動かすと表示も変わります** —
出るのはクリックした区画が選ぶ面の IO であって、見ている面の IO ではありません。

## 3. ハイライト

レンチを持っている間、次のものが描かれます。

| 見えるもの | 意味 |
|---|---|
| ポートの面の白い枠と 3 × 3 グリッド | 面ごとの IO を設定できる（上記） |
| ブロック全体の**緑の枠** | このレンチがリンクしているコントローラ |
| ブロック全体の**橙の枠** | 今見ているコントローラ（スニーク + 右クリックでリンクできる） |
| コントローラから伸びる線 | 登録済みの外部ポート。入力は青・出力は橙・入出力は紫 |
| 外部ポートに浮かぶ `[ 種別 : 方向 ]` | そのブロックが何としてどちら向きに登録されているか |

> [!NOTE]
> **リンク先のコントローラと外部ポートの線は、壁の向こうにあっても描かれます。**
> 機械の裏側で外部ポートを登録するときに、コントローラが見えないのが普通だからです。
>
> コントローラには 3 × 3 のグリッドを描きません。コントローラに面ごとの IO は無いので、
> グリッドを描くと存在しない操作を示してしまいます。

`[ 種別 : 方向 ]` の末尾に **`固定`** と付く場合は、その IO が構造定義側で固定されていて、
レンチでは変えられないことを意味します。

## 4. ツールチップ

- **アイテム名**に、選択中のポート種別が括弧つきで入ります（例: `レンチ (アイテム)`）。
  空中で右クリックして切り替えたとき、名前がそのまま変わります
- **リンク先**の行が、リンクしていれば座標つきの緑、していなければ黄で出ます

## 5. 保存されるもの

リンク先と選択中のポート種別は、**レンチのアイテム NBT** に入ります。
別のレンチに持ち替えると設定はついてきません。

外部ポートの登録そのものは**コントローラ側**に保存されます。レンチを捨ててもリンクが消えるだけで、
登録済みの外部ポートはそのまま動きます。
