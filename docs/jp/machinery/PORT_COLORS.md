# ポートの色分け

機械のポートを色で塗り分けると、**同じ色のポートだけが 1 つのまとまりとして扱われます**。
1 台の機械の中に、独立して材料を受け取る系統を複数作れます。

## 1. まとめ

同じ機械で複数種のレシピを管理したいときに使います。

- 赤いポートに入れた材料は、赤いポートから出てくる
- 青いポートに入れた材料は、青いポートから出てくる
- 赤と青が混ざってレシピが成立することがない
- 同時に走るレシピは 1 つだけで、並列処理ではありません。

## 2. 塗り方

| 操作 | 結果 |
|---|---|
| ポートを**染料で右クリック** | その色に塗る（染料を消費） |
| ポートを**水バケツで右クリック** | 色を落とす（水は消費しない） |
| AE2 の **Color Applicatorでシフト右クリック** | 塗る |
| IC2 の **Painterで右クリック** | 塗る |

染料も水バケツも持っていないときの右クリックは今までどおり GUI が開きます。
既に同じ色のときは染料を消費しません。

色は WAILA のツールチップにも出ます。

> [!NOTE]
外部ブロック（バニラのチェストなど）のポートはまだ色付け出来ません。
塗っていない扱いになるので、下のルールにより全ての色から共有されます。

## 3. レシピの実行順

| # | ルール |
|---|---|
| 1 | 塗ったポートは、自分の色のグループに入る |
| 2 | 塗っていないポートは、全色のグループに入る |
| 3 | グループを見る順番はメタデータ順。すなわち 白 → 橙 → 赤紫 → 空色 → 黄 → 黄緑 → 桃 → 灰 → 薄灰 → 青緑 → 紫 → 青 → 茶 → 緑 → 赤 → 黒 |
| 4 | 塗っていないポートだけのグループは最後に見る |
| 5 | コントローラ自身は色に関係なくすべてのまとまりに入る |

例えば以下の構成の場合ならばこうなる

```
赤ポート: アイテム入力・アイテム出力
青ポート: アイテム入力・アイテム出力
無色:     エネルギー入力 1 個

→ 赤グループ = 赤の入力・赤の出力・無色のエネルギー
→ 青グループ = 青の入力・青の出力・無色のエネルギー
```

塗っていない入力ポートに入れた材料は、どの色からも見えます。


## 4. レシピの選ばれ方

グループを順番に見て、最初に「レシピが成立して、かつ出力が入る」レシピを動かします。

> [!NOTE]
> 出力が塞がっているグループは飛ばされます。
> 赤の出力タンクが満杯でも、青は動きます。

どのグループも動かせなかったときは、優先度がいちばん高い色のエラーが GUI に出ます。

## 5. Tips

ポートを壊しても色は失われません。

順序つきポート位置（構造 JSON の `portIndex`）とは別の軸です。
色で分けたまとまりの中で番号が見られるので、両方を同時に使えます。
