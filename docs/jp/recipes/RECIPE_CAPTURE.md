# レシピのキャプチャ (Recipe Capture)

レシピのキャプチャは、機械のポートに入っているアイテムや液体から、レシピの JSON を作る機能です。
ID を手で打つ必要がありません。ポートに材料を入れ、コマンドを実行し、チャット上で下書きを直して、保存します。

## 流れ

1. 機械を建て、**完成した状態**にします。
2. 入力ポートに材料を、出力ポートに成果物を入れます。液体も入れられます。
3. コントローラーを見て（5 ブロック以内）、`/okmodular recipe capture <duration> [group]` を実行します。
4. `/okmodular recipe show` で下書きを確認します。量や所要時間を直し、要らない項目を消し、エネルギーを設定します。項目を足したいときは、ポートに入れてからもう一度キャプチャします。
5. `/okmodular recipe save` を実行します。レシピがファイルに追記され、レシピが再読み込みされます。

ポートの中身は**消費されません**。キャプチャは読むだけです。

## コマンド

すべて `/okmodular recipe` の下にあり、権限レベル 2 が必要です。

| コマンド | 内容 |
|---|---|
| `capture <duration> [group]` | 見ているコントローラーのポートを読んで、下書きを作ります。`duration` の単位は tick です |
| `show` | 下書きを表示します。各項目に `[amount]` と `[remove]` のボタンが付きます |
| `amount <number> <amount>` | `<number>` 番の項目の量を設定します（アイテムは個数、液体は mB） |
| `remove <number>` | `<number>` 番の項目を消します |
| `duration <ticks>` | レシピの所要時間を設定します |
| `energy <amount> [perTick]` | エネルギーを設定します。`perTick` の既定は `true`（1 tick あたりの RF）で、`false` なら合計です。`0` でエネルギーを消します |
| `save` | 下書きをグループのファイルに追記し、レシピを再読み込みします |
| `discard` | 下書きを捨てます |

番号は**入力が先、出力があと**の順に振られます。エネルギーには番号がありません。
`show` の `[amount]` と `[remove]` を押すと、コマンドがチャット欄に入るだけです。実行は自分で Enter を押します。

## キャプチャされるもの

- アイテムは ID とメタ値が同じものを、液体は名前が同じものを 1 つにまとめます。
- アイテムの量は 64 を超えてもかまいません。液体の量の単位は mB です。

## 保存先

`save` は `config/okmodular/recipes/captured/<file>.json` に追記します。

- `group` を省くと、コントローラーの最初のレシピグループになります。グループが無ければ `default` です。
- `<file>` は、グループ名のうち `[A-Za-z0-9_.-]` 以外の文字を `_` に置き換えたものです。Windows の予約名（`con`・`nul`・`com1` など）と `.`・`..` には、頭に `_` を付けます。たとえば `Ore Crusher` は `Ore_Crusher.json` に保存されます。
- ファイルが無ければ、`"group"` のヘッダー付きで作られます。ヘッダーにはグループ名をそのまま書くので、レシピは元の機械のものになります。
- 手で書いたファイルには触りません。
- キャプチャで作ったファイルが壊れているときは、保存を断り、ファイルはそのままにします。
- `registryName` の無いレシピには `captured_<file>_<n>` という名前が付きます。`n` はファイル内のレシピ数に 1 を足した数で、すでにある名前は飛ばします。名前を変えたいときは JSON を直接編集してください。
- `save` すると下書きは消えます。もう一度 `capture` を実行すると、いまの下書きは上書きされます。
- 下書きはプレイヤーごとに 1 つです。ログアウトとサーバー停止で消えます。

## キャプチャされないもの

次のものは、保存したあとで JSON に手で足してください。[レシピ JSON フォーマット](./JSON_FORMAT.md) を参照してください。

- NBT と NBT の照合
- 鉱石辞書
- ポートの番号
- ほかの資源（マナ・ガス・エッセンチア・ヴィス・ブロック・構造体）
- 確率と触媒
